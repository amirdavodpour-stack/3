# Branding assets

- `google_g.png` is a 96×96 transparent PNG rasterization of the standard-colour Google G mark distributed by the Google-maintained FirebaseUI Web repository at [`packages/core/brands/google/logo.svg`](https://github.com/firebase/firebaseui-web/blob/main/packages/core/brands/google/logo.svg). The vector's paths and brand colours were not modified; only the raster output size was changed for Flutter asset rendering.
- Use only inside the white, outlined Google sign-in button. Do not recolour, crop, add effects, or use as a generic app icon.
- Branding reference: [Google Identity Sign in with Google Branding Guidelines](https://developers.google.com/identity/branding-guidelines). Google states that the standard-colour G must not be recoloured and must appear on a white background.
